## 目录结构

walnutpi-1/
├── examples/          # 示例代码（按功能分类）
│   ├── 01_python_embedded/ # Python嵌入式
│   ├── 02_opencv/      # 机器视觉
│   ├── 03_pyqt5/       # 图形化显示│
